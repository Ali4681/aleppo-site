# نشر عرض حلب القديمة

ارفع محتويات هذا المجلد إلى مستودع GitHub مستقل.

## Vercel

New Project > اختر المستودع > Deploy.
إعدادات vercel.json تضبط المشروع كموقع Static بدون Build.
اترك Root Directory على جذر المستودع.

## Render

New > Blueprint > اختر المستودع لتطبيق render.yaml.
أو New > Static Site مع الإعدادات التالية:
Build Command: echo ready
Publish Directory: .

## الصفحات

/ : واجهة العرض الرئيسية (index.html).
/aleppo_model.html : النموذج الإضافي.

هذه نسخة من صفحات العرض المصدرة؛ تحديث ملفات Python أو البيانات الأصلية
لا يحدث الموقع تلقائياً. بعد إعادة التصدير انسخ الصفحات الجديدة إلى هذا
المجلد بنفس الأسماء ثم ارفع التحديث إلى GitHub.

حجم الصفحة الرئيسية حوالي 67 MB، لذا قد يستغرق أول تحميل بعض الوقت.
لا يحتاج الموقع إلى تشغيل Python على الاستضافة.
